# Расчетный движок

`backend/app/calculations/` — чистые функции: без БД, без сети, без LLM.
Один и тот же вход всегда дает один и тот же выход, поэтому движок легко
тестировать и версионировать (`FORMULA_VERSION`).

## Соглашения

- Ставки — доли: `0.145` означает 14,5 %.
- Цены — проценты от номинала: par = 100.
- Отсутствующий вход → результат `None`. Ноль не подставляется никогда.
- Дни считаются по конвенции выпуска: `ACT/365F` (по умолчанию), `ACT/360`,
  `30/360`, `ACT/ACT`.

## Функции

| Функция | Смысл |
|---|---|
| `calculate_cashflows` | график купонов и погашения, раскатанный назад от даты погашения |
| `calculate_accrued_interest` | НКД = номинал × ставка × доля года от прошлого купона |
| `calculate_current_yield` | годовой купон / уплаченная цена |
| `calculate_bond_price` | PV потока платежей при заданной доходности |
| `calculate_ytm` | доходность, воспроизводящая грязную цену (бисекция) |
| `calculate_duration` | дюрация Маколея, годы |
| `calculate_modified_duration` | `D / (1 + y/f)` |
| `calculate_convexity` | `Σ tᵢ(tᵢ+1/f)·CFᵢ·(1+y/f)^(−f·tᵢ) / (P·(1+y/f)²)` |
| `calculate_credit_spread` | YTM − безрисковая ставка того же срока |
| `calculate_bid_ask_spread` | абсолютный спред, mid и спред в долях от mid |
| `calculate_pull_to_par` | доход от схождения цены к номиналу (всего и в год) |
| `calculate_total_return` | (получено / вложено) − 1 |
| `calculate_annualized_return` | `(1+total)^(1/лет) − 1` |
| `calculate_real_return` | **формула Фишера** |
| `calculate_real_total_return` | `(1+total) / (1+i)^лет − 1` |
| `calculate_portfolio_ytm` | доходность портфеля, взвешенная по рыночной стоимости |
| `calculate_portfolio_duration` | duration портфеля, взвешенная так же |
| `calculate_weighted_score` | сведение подоценок в одну с перенормировкой весов |
| `calculate_scenario_price` | `ΔP/P = −D_mod·Δy + ½·C·Δy²` |

## Реальная доходность

```
real = (1 + nominal) / (1 + inflation) − 1
```

Простое вычитание `nominal − inflation` **не используется как основной
расчет**: при инфляции около 10 % оно завышает результат почти на процентный
пункт. Для многолетнего горизонта инфляция компаундируется:

```
real_total = (1 + total_return) / (1 + inflation)^лет − 1
```

Источник инфляции выбирается в настройках (`automatic`, `official`,
`forecast`, `manual`) и всегда возвращается вместе с числом, чтобы
пользователь видел, откуда оно взялось.

## Почему бисекция для YTM

Ньютон сходится быстрее, но может разойтись на выпусках с необычным графиком
платежей. Приведенная стоимость строго убывает по доходности, поэтому
бисекция на отрезке `[-0.95, 10.0]` сходится всегда. Если цена лежит вне этого
диапазона, функция возвращает `None`, а не приблизительное значение.

## Разделение ответственности

- Расчеты производных величин — `MetricsService` (сохраняет `BondMetric`).
- Оценки — `app/scoring/` (сохраняет `BondScore` + `ScoreComponent`).
- Фронтенд — только форматирование (`frontend/utils/format.ts`).
- LLM — только текст объяснения; ни одно число не приходит от модели.
